# Orca Landing Pages

דפי נחיתה שמוצגים בוורדפרס ישירות מהריפו הזה. כל commit לתיקיית `pages/` מתעדכן באתר תוך דקות. בלי FTP, בלי GitHub Actions.

## איך זה עובד

```
Claude Design → HTML → commit ל-pages/<שם>/index.html → וורדפרס מושך ומציג
```

באתר מותקן תוסף קטן (`wordpress/orca-landing-pages/`). בעמוד באלמנטור שמים ווידג'ט Shortcode:

```
[landing_page name="rachel-pottery"]
```

התוסף מושך את `pages/rachel-pottery/index.html` מגיטהאב, שומר בזיכרון ל-5 דקות, ומציג. אם גיטהאב לא זמין, מוצג העותק האחרון שנשמר.

## מבנה

```
pages/
├── rachel-pottery/index.html
├── mashpian/index.html
└── <שם-דף-חדש>/index.html
wordpress/
└── orca-landing-pages/orca-landing-pages.php   ← התוסף
```

## הוספת דף חדש

1. תיקייה חדשה תחת `pages/` עם `index.html` (מסמך HTML מלא או קטע, שניהם עובדים).
2. תמונות: או כתובות מלאות (העלאה למדיה של וורדפרס), או קבצים בתיקיית הדף עם נתיב יחסי (`images/x.jpg`). נתיב יחסי עובד רק אם הריפו ציבורי.
3. טופס לידים **לא** נכנס ל-HTML. הוא נשאר ווידג'ט Form של אלמנטור מתחת ל-Shortcode, כדי שהלידים יישמרו.
4. Push ל-main.

## תיקון דף קיים

עורכים את ה-HTML, commit, push. תוך 5 דקות זה באתר. לראות מיד: להוסיף `?olp_refresh=1` לכתובת הדף כשמחוברים כמנהל, או "נקה זיכרון" במסך ההגדרות בוורדפרס (הגדרות → דפי נחיתה (GitHub)).

## התקנת התוסף (פעם אחת לכל אתר)

1. לארוז (שם הקובץ תמיד עם מספר הגרסה): `cd wordpress && v=$(grep -m1 Version: orca-landing-pages/orca-landing-pages.php | awk '{print $3}') && zip -r orca-landing-pages-$v.zip orca-landing-pages`
2. וורדפרס → תוספים → העלאת תוסף → לבחור את ה-zip → הפעלה.
3. אם הריפו פרטי: הגדרות → דפי נחיתה (GitHub) → להדביק טוקן גיטהאב עם הרשאת קריאה לריפו. אם ציבורי, אין מה להגדיר.

## אופציונלי: עדכון מיידי בכל push

במסך ההגדרות לקבוע "סוד ל-webhook", ובגיטהאב Settings → Webhooks להוסיף:
`https://<האתר>/wp-json/olp/v1/refresh?secret=<הסוד>` על אירוע push.

## טפסים: תבניות אלמנטור

הטופס לא נמצא ב-HTML. לכל דף יש תבנית אלמנטור ב-`templates/<שם>-form.json`, שנבנית מסקריפט `templates/build_<שם>_form.py` (לערוך את הסקריפט, להריץ, לייבא מחדש). הקונטיינר מכיל: ווידג'ט HTML עם CSS בלבד, ווידג'ט Form אמיתי, מפריד "או" (HTML דקורטיבי), ווידג'ט Button אמיתי לוואטסאפ (הקישור נקבע בפאנל), וווידג'ט טקסט לפוטר. **כל מה שפועל הוא ווידג'ט של אלמנטור**, ה-HTML נושא רק עיצוב.

ייבוא (פעם אחת לכל אתר): תבניות → תבניות שמורות → ייבוא תבניות → לבחור את הקובץ. אחר כך בעמוד: מתחת ל-Shortcode, הוספת תבנית → "רחל - טופס".

**אחרי הייבוא לבדוק** שעל הקונטיינר יש את מחלקת ה-CSS (מתקדם → מחלקות CSS → `rachel-form`). הייבוא של אלמנטור לפעמים מוחק אותה, ובלעדיה העיצוב לא נתפס.

בטופס עצמו להגדיר: Actions After Submit (למי נשלח המייל / webhook), והודעת ההצלחה.

**שמות שדות בטופס (ID):** אסור להשתמש ב-`date`, `time`, `page_url`, `user_agent`, `remote_ip`, `form_id`, `form_name`. אלה שמות שאלמנטור עצמו שולח ב-webhook, והם דורסים את מה שהמשתמש הקליד. תאריך מבוקש = `visit_date`.

## עמודים חדשים נוצרים לבד (מגרסה 1.6.0)

`pages.json` בשורש הריפו מצהיר אילו עמודים צריכים להתקיים באיזה אתר:

```json
[{"site":"influence-club.co.il","name":"mashpian-cancel","slug":"cancel",
  "title":"משפיען בדיגיטל – ביטול מנוי","template":"templates/mashpian-cancel.json"}]
```

בכל push התוסף בודק: אם באתר אין עמוד עם ה-slug הזה, הוא יוצר אותו **כטיוטה** מתבנית העמוד (תוכן + הגדרות עמוד, Canvas). עמוד שכבר קיים לא נוגעים בו לעולם, כדי שמה שיהונתן ערך בעורך (נמען הטופס, פרסום) יישאר. מה שנשאר ליהונתן: לפתוח את הטיוטה, להגדיר Actions After Submit, ללחוץ פרסם.

## פוטר משותף לאתר (מגרסה 1.7.0)

`sites.json` בשורש מצהיר לכל אתר על פוטר: שם התיקייה ב-`pages/` וסימני זיהוי של הפוטר הישן שהודבק ידנית. בכל push התוסף עובר על כל העמודים באתר: אלמנט ראשי שמכיל את אחד הסימנים מוחלף בקונטיינר עם `[landing_page name="<פוטר>"]`, והמקור נשמר בגיבוי (`_olp_footer_backup`). עמודים שנוצרו מהריפו ואין להם פוטר מקבלים אחד בסוף. שאר העמוד לא נוגעים בו. מעכשיו תיקון בפוטר = עריכת קובץ אחד ו-push.

## עדכון עצמי של התוסף (מגרסה 1.7.2)

`wordpress/version.json` מצהיר על הגרסה האחרונה וכתובת ה-zip (ה-zip מחויב לריפו, זו חבילת העדכון). התוסף בודק את הקובץ הזה; גרסה חדשה מופיעה במסך התוספים של וורדפרס כעדכון רגיל, ובנוסף ה-webhook של push מתקין אותה מיד בעצמו. שחרור גרסה = לעדכן את מספר הגרסה בקובץ ה-PHP, לארוז zip עם השם החדש, לעדכן version.json, ולדחוף.

## המרת עמוד אלמנטור קיים ל-HTML מהריפו (מגרסה 1.9.0)

לאתר שכבר בנוי באלמנטור (orcatribe.co.il) ב-`sites.json` מצהירים אילו עמודים עוברים לריפו, לפי מספר העמוד בוורדפרס:

```json
{"orcatribe.co.il": {"convert": [{"page": 114, "name": "orca-home"}]}}
```

בכל push התוסף עובר על הרשימה. עמוד מומר **פעם אחת**, ורק אם `pages/<name>/index.html` כבר קיים בריפו:

1. העיצוב המלא של אלמנטור נשמר כתבנית בספרייה, בשם "גיבוי – <שם העמוד> – <תאריך>", ונקרא חזרה לאימות. אם הגיבוי נכשל, העמוד לא נגעים בו.
2. כל טופס לידים נשמר כתבנית נפרדת ("טופס – <שם העמוד> #n") ומוצג כטופס אלמנטור אמיתי במקום שבו ה-HTML כותב `<!--olp:form:n-->`. טופס שאין לו סימן ב-HTML מוצג בסוף העמוד, כך שאף טופס לא נעלם.
3. התוכן של העמוד הופך לווידג'ט Shortcode אחד. הכתובת, הכותרת, ה-SEO ותבנית העמוד לא משתנים.

**חזרה לאלמנטור:** `POST /wp-json/olp/v1/unconvert?page=<id>&secret=<הסוד>` מחזיר את העיצוב המקורי, ועמוד שהוחזר לא יומר שוב. או ידנית: לפתוח את העמוד באלמנטור ולהכניס את תבנית הגיבוי מהספרייה.

**רכיבים חיים (מגרסה 1.10.0):** בכניסת convert אפשר להוסיף `"keep": ["<element id>", ...]`. כל רכיב כזה (תפריט, וידאו, קרוסלה, כפתור שפותח פופאפ) נשמר כתבנית אלמנטור ("רכיב – <שם העמוד> – <id>") ומוצג במקום שבו ה-HTML כותב `<!--olp:keep:<id>-->`. העטיפות של התבנית שקופות לפריסה (display:contents), כך שהרכיב יושב בדיוק במקום המקורי. רכיב שלא נמצא בעמוד עוצר את ההמרה לפני כל שינוי.

**הקפאת עמוד קיים:** `tools/freeze_elementor_page.py <url> <page id> <name>` מעתיק עמוד אלמנטור חי ל-`pages/<name>/index.html` (הסימון והעיצוב של העמוד עצמו, כך שההעתק זהה), מסמן טפסים ורכיבים חיים, ומדפיס את רשימת ה-keep ל-sites.json. לבדוק לפני המרה מול בסיס הוגן: גלילה מלאה של העמוד פעמיים לפני הצילום (תמונות נטענות בגלילה), ופופאפ נבדק בלחיצה ולא בחיפוש ב-DOM.

**עיצוב מקלוד דיזיין (.dc.html):** `tools/dc_to_html.py <file.dc.html> pages/<name>/index.html [--form] [--drop-section LABEL]` ממיר את הפורמט של קלוד דיזיין לדף רגיל: אפקטי ריחוף הופכים ל-CSS, תנאי מחשב/נייד הופכים לבלוקים רספונסיביים, התפריט והאנימציות עוברים לסקריפט קטן, `--form` שם את טופס האלמנטור האמיתי במקום הטופס של העיצוב, ו-`--drop-section` מוציא סקשן (למשל טקסט דמה). מייצאים מקלוד דיזיין ב-Project archive.
