# הקמת תשתית בלוג לאתר אורקה טרייב

## מה יש בתיקייה הזו

| קובץ | מה הוא |
|------|--------|
| `orca-single-post.json` | תבנית Theme Builder לפוסטים (Single Post) |
| `orca-blog-content.css` | CSS לעיצוב תוכן המאמרים |
| `faqpage-post-422.json` | נתוני FAQPage למאמר הראשון |

## שלב 1: יצירת תבנית Single Post ב-Theme Builder

### בעורך של אלמנטור:
1. **Templates → Theme Builder → Single Post → Add New**
2. לבחור **Single Post** ולתת שם "אורקה - תבנית מאמר"
3. להגדיר את התנאי: **Posts → All**

### בתבנית עצמה לבנות:

**הדר (Header):**
- רקע: `#00132e`
- לוגו אורקה (קישור לעמוד הבית)
- ניווט: בניית מותג | ניהול קמפיינים | דברו איתנו (כפתור ורוד)

**אזור הכותרת:**
- רוחב: 800px ממורכז
- רקע: `#001b3f`
- ווידג'ט **Post Title** (דינמי): Heebo 900, 42px, לבן, ממורכז
- ווידג'ט **Post Info** (תאריך): Heebo 400, 15px, אפור בהיר

**תוכן המאמר:**
- רוחב: 760px ממורכז
- ווידג'ט **Post Content** (דינמי)
- להוסיף את ה-CSS מקובץ `orca-blog-content.css` (מתקדם → Custom CSS)
- מחלקת CSS על הקונטיינר: `orca-blog-content`

**CTA בסוף:**
- רקע: `rgba(0,19,46,0.6)` עם border-radius 24px
- כותרת: "רוצה שנעזור לך להגיע ללקוחות?"
- תת-כותרת: "השאר פרטים ונחזור אליך תוך יום עסקים אחד"
- הטופס: Shortcode `[elementor-template id="390"]` (הטופס של עמוד הבית)

**פוטר:**
- רקע: `#00132e`
- לוגו, קישורים לעמודים משפטיים, זכויות יוצרים

## שלב 2: הוספת FAQPage Schema (ב-Yoast)

1. לפתוח את הפוסט 422 לעריכה
2. ב-Yoast → Schema → Page type: "FAQ page"
3. או: להוסיף את התוכן של `faqpage-post-422.json` כבלוק Schema ידני

**חלופה אם Yoast לא תומך:**
להוסיף את ה-JSON הזה לפוסט (בקוד מותאם או דרך תוסף):
```html
<script type="application/ld+json">
... (תוכן faqpage-post-422.json)
</script>
```

## שלב 3: יצירת קטגוריה "בלוג"

1. Posts → Categories → Add New
2. שם: "בלוג"
3. Slug: `blog`
4. לשייך את פוסט 422 לקטגוריה

## שלב 4 (אופציונלי): עמוד ארכיון בלוג

אפשרות א': להשתמש בקטגוריה `/category/blog/`
אפשרות ב': ליצור עמוד "בלוג" עם Theme Builder (Archive template)

**שאלה ליהונתן:** האם לקשר לבלוג מההדר או מהפוטר?
