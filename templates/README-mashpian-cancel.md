# משפיען בדיגיטל – ביטול מנוי

- דף: `pages/mashpian-cancel/index.html` (פונטים + CSS של האתר + התאמות + הירו). מוצג דרך `[landing_page name="mashpian-cancel"]`.
- תבנית עמוד: `templates/mashpian-cancel.json` — תבנית מסוג **עמוד** (Canvas, רקע #0A0A0D) שמכילה: קונטיינר עם ה-Shortcode, קונטיינר `lp-formcard lp-cancel` עם ווידג'ט Form (שם מלא, תעודת זהות, המייל שאיתו נרשמת, טלפון; כפתור "שליחת בקשת ביטול"), וקונטיינר ריווח תחתון.
- ייבוא: תבניות → תבניות שמורות → ייבוא. עמוד חדש → עריכה עם אלמנטור → סמל התיקייה → התבניות שלי → "משפיען בדיגיטל – ביטול מנוי" → הוספה → לאשר "החל הגדרות עמוד".
- אחרי ההוספה לבדוק: הקונטיינר של הטופס → מתקדם → מחלקות CSS = `lp-formcard lp-cancel`. הטופס → Actions After Submit → אימייל: למי נשלחת בקשת הביטול.
