# פרופיל · דף כהה ויוקרתי · סגנון משפיען

**שם קוד:** "דף כהה ויוקרתי", "סגנון משפיען", "פרימיום כהה".
**אופי:** יוקרתי, חד, סמכותי, ממוקד המרה.
**מקור:** influence-club.co.il — משפיען בדיגיטל. פלטה מחייבת מ-13/09/2026.

**מתי:** מוצר דיגיטלי, קורס, פורטל, הכשרה, שירות פרימיום. קהל קר שמגיע מקמפיין ממומן וצריך להשתכנע בתוך הדף.

**מתי לא:** עסק מקומי של אדם אחד שמוכר חוויה או עבודת יד. שם זה ייראה קר ומרוחק — עבור לעדין ואומנותי.

## רקע

**לעולם לא שחור שטוח.** תמיד גרדיאנט עם עומק: בסיס כהה, ומעליו גרדיאנטים רדיאליים בצבעי ההדגשה באטימות נמוכה. אופציונלי: `repeating-linear-gradient` לתבנית עדינה.

## מספרים — ערכים אמיתיים מהדף החי

נשאבו מ-`pages/mashpian/index.html`.

| | ערך |
|---|---|
| רוחב קונטיינר מקסימלי | `900px` עד `1000px` |
| עיגול פינות — כרטיס | `16px`, `22px` או `24px` |
| עיגול פינות — כפתור ותגית | `999px` (גלולה) |
| זוהר חזק (כפתור פעולה) | `0 0 56px rgba(232,89,12,.55)` |
| זוהר בינוני | `0 0 40px rgba(232,89,12,.35)` |
| זוהר אווירה (רקע סקשן) | `0 0 70px rgba(255,122,26,.09)` |
| ריווח סקשן בדסקטופ | `88px 64px` |
| ריווח פנימי בכרטיס | `26px 28px` |

**זוהר, לא צל.** `0 0 Npx` בצבע ההדגשה. אין `rgba(0,0,0,…)` ואין היסט אנכי.

## לקוח חדש בפרופיל הזה

אין לו עדיין פלטה? **לא משתמשים בכתום־נייבי של משפיען** — זו התנגשות מותג. בונים איתו: רקע כהה מצבע המותג, צבע פעולה חם אחד, צבע קישוט קר אחד, ומאשרים מול יהונתן לפני הבנייה.
